# CleanMap Tripura

CleanMap is a lightweight, responsive concept website about a clearer community-level view of local cleanliness in Tripura. It is an independent prototype, not an official government service.

## Run locally

```powershell
npm.cmd install
npm.cmd run dev
```

Open the local URL printed by Vite. The site is a static React/Vite experience and does not require an API server or environment variables.

## Build

```powershell
npm.cmd run lint
npm.cmd run build
```

The previous app source is preserved in the checkpoint branch and in a local archive outside this project workspace. This fresh site does not connect to Supabase or use an API. The existing Supabase project and its data were not changed.
