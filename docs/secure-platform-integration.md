# Previous application architecture

This document describes an earlier version of CleanMap and is retained as a historical reference. Its authentication, API, database, environment, deployment, and security setup instructions do not apply to the current concept website.

The current website is a static React/Vite prototype. It has no login screen, API server, database connection, or Supabase client. The existing Supabase project and its data were left unchanged.

For the earlier implementation, use the `codex/basic-cleanmap-public-site` checkpoint branch. Do not copy its credentials or environment configuration into this static site.
